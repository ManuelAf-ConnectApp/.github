# ConnectApp

### Open Source Software · Privacy First · Freedom to Create

Welcome to **ConnectApp**, an independent initiative dedicated to developing and sharing open-source applications that prioritize privacy, transparency, and code reusability.

Our goal is to provide developers with reliable, well-structured applications that can be studied, modified, extended, and used as foundations for new software projects.

🌐 **Website:** https://www.connectapp.es  
💻 **GitHub:** https://github.com/ManuelAf-ConnectApp

---

## 🚀 Our Mission

ConnectApp believes that software should be accessible, transparent, and respectful of users' privacy.

We develop applications following four fundamental principles:

- **Open Source:** Source code is publicly available for learning, modification, and reuse.
- **Privacy First:** Applications are designed to minimize unnecessary data collection and external dependencies.
- **Local-First Approach:** Whenever possible, application data is stored and processed locally.
- **Clean Architecture:** Projects aim to follow maintainable, scalable, and reusable software development practices.

Our applications are intended to serve both end users and developers looking for solid foundations for their own projects.

## ⚙️ Repository Purpose

This `.github` repository provides centralized community guidelines and configuration files for ConnectApp projects.

Its purpose is to maintain consistency across repositories and simplify project administration.

### Shared Configuration

The repository may include:

- `FUNDING.yml` — GitHub Sponsors configuration.
- `CONTRIBUTING.md` — Contribution guidelines.
- `CODE_OF_CONDUCT.md` — Community standards.
- `SECURITY.md` — Security vulnerability reporting guidelines.
- `SUPPORT.md` — Support information.
- `ISSUE_TEMPLATE/` — Standardized issue templates.

Individual projects can override supported default configurations when necessary.

## 🔐 Privacy & Transparency

Privacy is one of ConnectApp's fundamental principles.

Whenever technically feasible, our applications aim to:

- Store user data locally.
- Avoid unnecessary third-party services.
- Minimize external data transmission.
- Provide clear documentation about data processing.
- Give users greater control over their information.

Open-source availability enables independent code inspection, although privacy and security depend on each application's actual implementation.
